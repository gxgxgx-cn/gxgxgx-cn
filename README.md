## 你好，欢迎来到我的 GitHub 👋

我专注于**数据挖掘**与**人工智能**，同时长期投入**历史学**与**计量史学**研究——尝试用数据科学的方法，重新审视传统史学中的老问题。

> 用 AI 读史书，用数据看历史。

---

### 🔭 当前方向

- **AI × 历史研究**：借助大语言模型与文本挖掘技术，对《明史》等传统史料进行结构化整理、自动抽取与交叉验证，让史料"体检"变得可复现。
- **计量史学（Cliometrics）**：把职官、人口、灾异、财政等历史信息转化为可分析的数据，用统计方法回答史学问题。
- **数据挖掘与机器学习**：构建从原始文本到知识与结论的数据处理与分析流水线。

### 🌱 进行中的项目

- **MingAI** —— AI 驱动的明代历史研究工具箱：史料数字化、实体抽取、一致性校验与可视化分析。（仓库整理中，即将公开）
